# project-uap-game-gunting-batu-kertass

Game Batu Gunting Kertas

>Deskripsi

Game Batu Gunting Kertas merupakan permainan sederhana. Pemain akan bermain melawan komputer dengan memilih salah satu dari tiga pilihan, yaitu Batu, Gunting, atau Kertas.
Komputer akan menentukan pilihannya secara acak, kemudian program akan membandingkan kedua pilihan untuk menentukan hasil permainan.

>Fitur

- Pemain melawan komputer.
- Pilihan komputer secara acak.
- Menampilkan hasil menang, kalah, atau seri.
- Menghitung skor pemain dan komputer.
- Fitur bermain kembali (Replay).

>Teknologi

- Bahasa Pemrograman: C++
- Library: iostream, cstdlib, dan ctime.
